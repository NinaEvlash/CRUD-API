# CRUD-API

### Prerequisites

1. Install [Node.js](https://nodejs.org/en/download/)
2. Clone repository: https://github.com/NinaEvlash/CRUD-API.git
3. Go to folder `CRUD-API`
4. To install all dependencies use [`npm install`](https://docs.npmjs.com/cli/install)

---

### Test scripts

```bash
# run in development mode
$ npm run start:dev

# run in production mode
$ npm run start:prod

# run tests for API
$ npm run start:test

# run multiple instances of application
$ npm run start:multi
```
